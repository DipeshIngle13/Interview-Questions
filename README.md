# Interview Questions

A collection of interview questions built together with friends.
Add the questions you were asked in your interviews so everyone can benefit.

## Categories

| Folder | Description |
|--------|-------------|
| `python/` | Python questions |
| `fastapi/` | FastAPI questions |
| `ai/` | AI / ML / LLM questions |

## How to contribute

1. **Fork** this repo
2. Clone your fork
3. Create a new branch: `git checkout -b add-company-questions`
4. Add your questions (see [CONTRIBUTING.md](CONTRIBUTING.md) for the format)
5. Commit and push
6. Open a **Pull Request** on GitHub

Every PR is reviewed and will be merged only after approval.

## Note
Direct pushes to the `main` branch are not allowed.
